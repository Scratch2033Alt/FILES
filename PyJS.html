PyJS Documentation

Note: This documentation assumes you have the PyJS backend service (`apps/python_api_service/index.py`) and the `python.js` frontend library properly set up and running on your server.

Introduction to PyJS

PyJS is a powerful system that bridges the gap between Python backend execution and frontend JavaScript. It allows you to run Python code directly from your HTML and JavaScript, making it possible to execute server-side logic in a seemingly client-side manner, manage Python worker sessions, and dynamically load external JavaScript libraries.

This system leverages a Flask backend API (/python_api_service) for Python execution and a lightweight JavaScript library (python.js) for seamless frontend interaction.

Getting Started

To use PyJS in your HTML page, simply include the python.js script in your HTML <head> or before your closing </body> tag:

<!DOCTYPE html>
<html>
<head>
    <title>My PyJS App</title>
    <!-- Tailwind CSS for styling (optional) -->
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
    <!-- Your HTML content -->

    <!-- Include the PyJS library -->
    <script src="python.js"></script>
    <script>
        // Your JavaScript code can now use the 'Python' object
        // and 'loadScript' function
        async function initPyJS() {
            // Optional: Register a worker on page load
            await Python.Register();
            console.log("PyJS worker ready!");

            // Optional: Process all  tags on the page
            await Python.ProcessHTML();
        }
        initPyJS(); // Call the initialization function
    </script>
</body>
</html>

The Python JavaScript Object API

The python.js library exposes a global Python object with several asynchronous methods to interact with the backend Python API.

Python.Register()

Registers a new Python worker session on the backend. This creates an isolated in-memory environment for your Python code execution and stores a unique worker ID in the database.

  • Returns: A Promise that resolves with the worker_id (string) if successful.
  • Usage:
async function registerNewWorker() {
    try {
        const workerId = await Python.Register();
        console.log('New worker registered with ID:', workerId);
        // Store workerId or update UI
    } catch (error) {
        console.error('Failed to register worker:', error);
    }
}
registerNewWorker();

Python.Run(code, [workerId])

Executes Python code within the specified worker's interpreter session. If no workerId is provided, it uses the Python.workerId property (the last registered worker).

Security Warning: The backend uses exec() to run the provided Python code. This is highly insecure for untrusted user input as it allows arbitrary code execution on the server. For production environments, robust sandboxing (e.g., Docker containers, secure execution environments) is absolutely critical.

  • Parameters:
    • code (string): The Python code to execute.
    • workerId (string, optional): The ID of the worker to run the code on.
  • Returns: A Promise that resolves with the output (string) of the code execution.
  • Usage:
async function runPythonCode() {
    const myCode = `
import math
print("The value of pi is:", math.pi)
a = 10
b = 20
print(f"Sum: {a + b}")
`;
    try {
        const output = await Python.Run(myCode);
        console.log('Python Code Output:', output);
    } catch (error) {
        console.error('Error running Python code:', error);
    }
}
runPythonCode();

Python.Output([workerId])

Retrieves the full accumulated output (stdout/stderr) from the worker's interpreter session since its registration or last reset. If no workerId is provided, it uses the Python.workerId property.

  • Parameters:
    • workerId (string, optional): The ID of the worker.
  • Returns: A Promise that resolves with the accumulated output (string).
  • Usage:
async function getFullOutput() {
    try {
        const fullOutput = await Python.Output();
        console.log('Full Worker Output:', fullOutput);
    } catch (error) {
        console.error('Error getting full output:', error);
    }
}
getFullOutput();

Python.OutputLastCode([workerId])

Retrieves only the output from the most recent Python.Run() call for the specified worker. If no workerId is provided, it uses the Python.workerId property.

  • Parameters:
    • workerId (string, optional): The ID of the worker.
  • Returns: A Promise that resolves with the last code execution's output (string).
  • Usage:
async function getLastOutput() {
    try {
        const lastOutput = await Python.OutputLastCode();
        console.log('Last Code Output:', lastOutput);
    } catch (error) {
        console.error('Error getting last output:', error);
    }
}
getLastOutput();

Python.Require(modulename, [workerId])

Conceptually installs a Python package (via pip) into the worker's environment. In the current demo backend, this is a placeholder and does not perform actual installation. For a real system, this would involve running pip within the worker's isolated environment.

  • Parameters:
    • modulename (string): The name of the Python module to install (e.g., 'requests').
    • workerId (string, optional): The ID of the worker.
  • Returns: A Promise that resolves with a status message (string).
  • Usage:
async function installPackage() {
    try {
        const message = await Python.Require('numpy');
        console.log(message);
    } catch (error) {
        console.error('Error requiring module:', error);
    }
}
installPackage();

Python.Quit([workerId])

Terminates the specified worker's Python interpreter session, removes its in-memory state, and deletes its entry from the MySQL database. If no workerId is provided, it uses the Python.workerId property.

Workers are also automatically quit after 30 seconds of inactivity (no API calls to that worker).

  • Parameters:
    • workerId (string, optional): The ID of the worker to quit.
  • Returns: A Promise that resolves with a status message (string).
  • Usage:
async function quitCurrentWorker() {
    try {
        const message = await Python.Quit();
        console.log(message);
        // Clear worker ID from UI
    } catch (error) {
        console.error('Error quitting worker:', error);
    }
}
quitCurrentWorker();

Python.ProcessHTML()

Scans the entire HTML document for custom <py> tags. For each tag found, it extracts the Python code, automatically corrects its indentation, sends it to the backend for execution, and replaces the content of the <py> tag with the Python's output or an error message.

If no worker is currently registered (i.e., Python.workerId is null), it will automatically call Python.Register() first.

  • Returns: A Promise that resolves when all <py> tags have been processed.
  • Usage:
// Typically called on page load after the DOM is ready
document.addEventListener('DOMContentLoaded', async () => {
    await Python.ProcessHTML();
});

Using the <py> Tag

The <py> tag allows you to embed Python code directly within your HTML. The Python.ProcessHTML() function will find these tags, execute their content, and display the output in place.

The system automatically handles common indentation issues for embedded Python code, so you can indent your Python code within the HTML for readability without causing IndentationError.

  • Example:
<py>
    # This is Python code embedded in HTML
    name = "World"
    print(f"Hello, {name} from PyJS!")
    for i in range(3):
        print(f"Iteration {i+1}")
</py>

After Python.ProcessHTML() runs, the above tag's content might be replaced with:

Hello, World from PyJS!
Iteration 1
Iteration 2
Iteration 3

Dynamic Script Loading (loadScript)

The python.js file also provides a utility function loadScript(url) that allows you to dynamically load external JavaScript files into your page. This is useful for loading third-party libraries on demand.

  • Parameters:
    • url (string): The URL of the JavaScript file to load.
  • Returns: A Promise that resolves when the script is loaded, or rejects on error.
  • Usage:
async function loadJQuery() {
    try {
        await loadScript('https://cdnjs.cloudflare.com/ajax/libs/jquery/3.6.0/jquery.min.js');
        console.log('jQuery loaded!');
        // You can now use jQuery, e.g., $('body').append('<p>jQuery added this!</p>');
    } catch (error) {
        console.error('Failed to load jQuery:', error);
    }
}
loadJQuery();

Conclusion

PyJS offers a flexible way to integrate Python execution into your web applications. By understanding the Python object's API and the convenience of the <py> tag, you can build dynamic web experiences powered by Python.

Remember to always prioritize security, especially when dealing with code execution from user input in a production environment.
